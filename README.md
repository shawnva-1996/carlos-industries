# carlos-industries

Website for **RB** (carlos-industries.vercel.app): three kitchens under one roof.

- **TSS · The Strange Smoke**: Filipino barbecue (`tss.html`)
- **1451 Café**: Batangas coffee (`1451.html`)
- **AD Bakery**: Filipino hard biscuits, mamon tostado (`ad.html`)

Plain static HTML/CSS/JS, no build step. Vercel serves the repo root (`vercel.json` turns on clean URLs, so `/tss` works).

Images are placeholders: every `<div class="ph" data-label="...">` marks where a real photo goes. Address, hours and contact details are marked `[to follow]`.

Copy is Taglish, written in the warm, plain, question-led voice of `hbf/SOT/HBF_WRITTEN_VOICE.md`. Layout follows 11co.one.
